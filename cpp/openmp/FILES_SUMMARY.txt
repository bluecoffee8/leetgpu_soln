================================================================================
DEMONSTRATION OF 9 REDUCTION METHODS
================================================================================

1. PARALLEL FOR WITH REDUCTION CLAUSE
   #pragma omp parallel for reduction(+:sum)
   → Most common, efficient, recommended for most cases
   → Compiler automatically creates private copies and combines

2. PARALLEL REGION WITH MANUAL WORK-SHARING
   #pragma omp parallel
   #pragma omp for
   → Shows manual thread work distribution
   → Each thread accumulates locally, then combines

3. CRITICAL SECTION
   #pragma omp critical { sum += local_sum; }
   → Safe but slow - serializes access
   → Only one thread enters critical block at a time

4. ATOMIC OPERATION
   #pragma omp atomic
   sum += local_sum;
   → More efficient than critical for simple operations
   → Hardware-supported atomic instructions

5. TASKLOOP REDUCTION
   #pragma omp taskloop reduction(+:sum)
   → OpenMP 4.5+, uses task-based parallelism
   → Good for irregular workloads

6. LOCKS
   omp_lock_t lock; omp_init_lock(&lock);
   omp_set_lock(&lock); ... omp_unset_lock(&lock);
   → Demonstrates explicit lock-based synchronization
   → Educational and fine-grained control

7. SIMD REDUCTION
   #pragma omp parallel for simd reduction(+:sum)
   → Explicitly hints for vectorization
   → Often fastest on modern CPUs due to auto-vectorization

8. SCHEDULE(STATIC)
   #pragma omp parallel for reduction(+:sum) schedule(static)
   → Static work distribution (determined at compile time)
   → Good for balanced workloads, minimal overhead

9. SCHEDULE(DYNAMIC)
   #pragma omp parallel for reduction(+:sum) schedule(dynamic, 1000)
   → Dynamic work distribution (assigned at runtime)
   → Good for unbalanced workloads, higher overhead

================================================================================
COMPILATION NOTES
================================================================================

MACOS:
  - Requires GCC (g++-15) from Homebrew
  - Default clang++ does NOT support -fopenmp
  - Install: brew install gcc
  - Compile: g++-15 -O3 -fopenmp ...

LINUX:
  - Use system g++ (usually supports -fopenmp)
  - Compile: g++ -O3 -fopenmp ...

WINDOWS:
  - Use MinGW with GCC or MSVC with OpenMP support
  - Compile: g++ -O3 -fopenmp ... (MinGW)

FLAGS:
  -O3       = Maximum optimization level
  -fopenmp  = Enable OpenMP support (GCC only)
  -c        = Compile to object file (don't link)
  -o file   = Output filename
